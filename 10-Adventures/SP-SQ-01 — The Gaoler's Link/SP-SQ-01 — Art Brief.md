# SP-SQ-01 — Art Brief

Midjourney prompts for SP-SQ-01. All prompts use the house black-and-white ink style for print ([[Art-Style-Guide]]) and `--v 8.1`. The sigils share `--seed 26576` so the six render as one set. Once the first sigil is approved, lock it as `--sref` for the rest. Files go in `99-Assets/SP-SQ/handouts/`, named as listed under each prompt. Ward names are used rather than gods' names, so the file names survive the Kestrel edition.
