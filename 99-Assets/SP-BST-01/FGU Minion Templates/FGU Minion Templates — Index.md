## Using them in FGU
1. **Import once per campaign:** open **NPCs → Import Text**, choose mode **2022 – Monsters of the Multiverse**, and paste the block for your party's APL. Import only the types and APLs you need; you can always come back for more.
2. **Keep the template clean:** leave the imported record named `Brute Minion (APL 5)` as a master copy.
3. **Reskin for the fight:** drag the master onto the Combat Tracker (or copy it in the NPC list), then rename it ("Gnoll Brute"), set the token, and change the **damage type** and **size/type** if the creature calls for it (a fire cultist's Shot is fire, a skeleton's Strike is bludgeoning and it's undead). Add darkvision or a speed if it matters.
4. **Drag in as many as you need.** With 1 hit point, FGU drops each one on any hit. The Minion trait reminds you that a successful save against half damage means no damage. FGU won't automate that, so apply it by hand.
5. **Level up:** when the party gains a level, import the next APL's block and retire the old one.

## Notes
- These are generic. For a named pack built from a specific monster (the drovers on the Erlen Bridge, Thorne's specters), see the **Minion Pack** in that scene's note.
- Saving throws use each type's ability spread with no proficiency, so a Brute resists shoves and an Artillery minion dodges fireballs a little better.
- **Regenerate, don't hand-edit.** These notes come from a script. If the Minion Table changes, ask Claude to regenerate all 140.
