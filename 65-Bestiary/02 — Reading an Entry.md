# Reading an Entry

Every entry follows the same order, so you can find what you need at the table.

| Section | What it's for |
|---|---|
| **Read-aloud line** | The first thing the players see. Twenty-five words or fewer. |
| **Statblock** | Complete 2014 rules. You don't need another book to run the creature. |
| **Lore** | What it is, where it comes from, and what people believe about it. |
| **Ecology** | Environment, how many appear together, and the signs that warn of it. |
| **Tactics** | How it fights, what it wants, and when it flees or bargains. A **Running it** note gives advice for the DM. |
| **Lair / Regional Effects** | For creatures with a home ground. |
| **Variants** | Alternate versions with the changes spelled out. |
| **Named Example** | For villain types: the individual from a Sidebar Press adventure, and what is unique to them. |
| **Adventure Hooks** | Three seeds, each with a twist. |
| **Spoils** | What the party can take, sell, or earn. |
| **Design Notes** | Changes from any *Monster Manual* base block, the CR verification, and folklore sources. |

## Origins
Each creature is tagged with one origin:
- **Harvested:** first appeared in a Sidebar Press adventure.
- **New:** an original creation.
- **Remix:** a classic monster reworked around a new idea.
- **Folklore:** drawn from real-world tradition, with game statistics of our own.
- **Contributed:** created by a Writers Guild member and credited by name under the title.

## Haunts and Templates
A **haunt** (such as the [[Toiling Haunt]]) isn't a combatant. Its block lists detection, manifestation, and resolution instead of attacks. A **template** (such as the [[Bone Beast Template]]) changes an existing statblock. Apply it, and the entry tells you whether the CR changes.
