## Making a new minion
1. Pick the source statblock and the minion type.
2. Read the row for the party's APL in [[04 — Minions]] (or ask Claude to build it).
3. Add the pack under the scene's `### Minion Pack (just in case)` heading; the Scene template already has the slot.
4. For Fantasy Grounds, import the matching APL block from the type's FGU templates note and reskin it.
