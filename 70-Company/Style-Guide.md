# Sidebar Press Style Guide

## Voice
Adventures are written for the DM, not the players. Clear, direct, skimmable. Boxed text is evocative but short — never more than ~120 words per box.

## Formatting
- **Bold** monster/NPC names on first mention in a scene
- *Italics* for read-aloud text only
- `Code` for adventure codes (A01) and FG module references
- `[[Wikilinks]]` for every named NPC, location, item, and plot thread

## Stat Blocks
2014 5e only. Reference the Monster Manual by name where possible; custom stat blocks go inline in the adventure note and get an NPC/Item note if they recur.

## Greyhawk Canon
- Cite edition, book, page for every canon claim
- Never use 5.5e-only lore
- When editions contradict, the Lore note records the conflict and our stance
- Homebrew is always labeled. Canon notes never contain it.

## Continuity Discipline
- Every adventure opens, advances, or closes at least one plot thread
- Dangling hooks are deliberate and logged in [[Plot-Threads]]
- Session logs feed back into thread statuses
