# Publishing Checklist

Run every adventure through this before release. Copy into the adventure's note or track here.

## Writing
- [ ] Adventure complete per [[90-Templates/Adventure]]
- [ ] All NPCs, locations, items have their own notes
- [ ] Canon check passed (no 5.5e lore, sources cited)
- [ ] Continuity section filled (threads opened/advanced/closed)
- [ ] Read-aloud text marked clearly
- [ ] Encounter balance sanity-checked for stated level range

## Editing
- [ ] Developmental edit (structure, pacing)
- [ ] Copy edit (grammar, consistency)
- [ ] Stat blocks verified against 2014 5e rules

## Fantasy Grounds
- [ ] Module built per FG checklist in adventure template
- [ ] Playtested in FG at least once
- [ ] Export versioned (v1.0, v1.1...)

## Release
- [ ] Listed in [[Release Tracker]]
- [ ] Announced on RPGSidebar.com
- [ ] Product page copy written
